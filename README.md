# 🛰️ God's Eye View – «Взгляд Бога»

**Браузерный симулятор спутника с 3D-Землёй в реальном времени**

**Автор проекта:** Павел Афанасьев  
**Контакты:** Email xongphavietnam@gmail.com | Telegram @PaulPavel_it_dev

## 📖 О проекте

God's Eye View — это интерактивное веб-приложение, которое превращает ваш браузер в командный центр наблюдения за планетой. Проект строит фотореалистичную трёхмерную модель Земли и отображает на ней движение объектов в режиме реального времени.

Павел Афанасьев разработал этот симулятор с нуля, вдохновляясь современными технологиями визуализации и интерактивными веб-интерфейсами. Всё работает прямо в браузере — без установки дополнительного ПО.

## ✨ Возможности

- Реалистичная 3D-Земля — текстуры высокого разрешения, атмосферные эффекты и динамическое освещение.
- Отслеживание объектов в реальном времени — воздушные суда, корабли, искусственные спутники и другие объекты.
- Отображение природных и географических событий в единой интерактивной сцене.
- Переключение визуальных режимов: обычный, CRT-стиль, ночное зрение и тепловизионный (FLIR).
- Иммерсивные камеры: вид от первого лица, тактический HUD и автоматический кинематографичный режим.
- Голосовое управление на русском языке для работы с интерфейсом и навигации.
- Адаптивная производительность для разных устройств и условий подключения.

## 🌍 Интерактивная карта планеты

Все доступные объекты и события визуализируются в единой трёхмерной сцене. Пользователь может исследовать Землю, изменять масштаб, переключать режимы отображения и наблюдать за динамическими объектами непосредственно в браузере.

## ⚙️ Установка и запуск

Проект работает как современное веб-приложение.

### Требования

- Node.js версии **24.14.x или 26.x** (ранние версии не поддерживаются; требование задаёт `engines` в `package.json`)
- Современный браузер с поддержкой WebGL

### Шаги

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/paulafanasyev/-_-
   cd -_-
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Настройте переменные окружения — создайте файл `.env` в корне проекта и добавьте необходимые параметры. Используйте `.env.example` как ориентир, если он присутствует в проекте.

4. Запустите сервер разработки:

   ```bash
   npm run dev -- --host localhost --port 4173
   ```

5. Откройте в браузере: `http://localhost:4173`

Для продакшн-сборки используйте `npm run build` и `npm run preview`.
