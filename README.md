## ⚠️ Об этой версии

Это **русская локализованная версия** проекта [God's Eye View](https://github.com/bilawalsidhu/gods-eye-view). Оригинальный проект, его авторство, лицензия и уведомления об авторских правах сохраняются.

Цель этой версии — предоставить полноценный русскоязычный интерфейс, документацию и голосовые команды, не изменяя программные идентификаторы, API-ключи и технические протоколы там, где их изменение может нарушить работу приложения.

## 🛰️ Возможности

- 🛩️ режим кабины отслеживаемого воздушного судна;
- 📡 список объектов в радиусе вокруг выбранной точки;
- 🎯 отслеживание самолётов, судов и других объектов;
- 🖊️ голосовые аннотации и маршруты на глобусе;
- 🛫 3D-модели воздушных судов;
- 🎨 режимы изображения: обычный, CRT, ночное видение, FLIR/тепловизор, Noir и Snow;
- 🟩 детекционные рамки и идентификаторы объектов;
- 🎖️ тактический HUD;
- 🌐 глобальный контекст;
- 🎥 кинематографический режиссёр сцен;
- 🔗 ссылки для обмена состоянием карты;
- 🏠 возврат к виду всей Земли;
- 🎙️ голосовое управление через realtime AI.

## 🌍 Источники данных

Проект использует открытые источники данных, среди которых OpenSky/adsb.lol, AISStream, CelesTrak, USGS, OSM, NASA FIRMS, GBFS, Launch Library 2 и публичные городские источники камер. Некоторые сервисы требуют API-ключи.

## ⚡ Быстрый запуск

Требуется Node.js версии, указанной в `package.json` исходного проекта.

```bash
npm install
npm run dev -- --host localhost --port 4173
```

После запуска откройте `http://localhost:4173`.

Переменные окружения задаются через `.env` на основе `.env.example`. Секретные ключи не должны помещаться в исходный код или публиковаться в репозитории.
