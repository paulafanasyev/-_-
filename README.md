# 🛰️ God's Eye View – «Взгляд Бога»

**Браузерный симулятор спутника с 3D-Землёй в реальном времени**

**Автор проекта:** Павел Афанасьев  
**Контакты:** Email xongphavietnam@gmail.com | Telegram @PaulPavel_it_dev

## 📖 О проекте

God's Eye View — это интерактивное веб-приложение, которое превращает ваш браузер в командный центр наблюдения за планетой. Используя открытые данные с реальных сенсоров и трекеров, проект строит фотореалистичную трёхмерную модель Земли и отображает на ней движение тысяч объектов в режиме реального времени.

Павел Афанасьев разработал этот симулятор с нуля, вдохновляясь современными технологиями визуализации и открытыми API. Всё работает прямо в браузере — без установки дополнительного ПО.

## ✨ Возможности

- Реалистичная 3D-Земля – текстуры высокого разрешения, атмосферные эффекты, динамическое освещение.
- Отслеживание объектов в реальном времени:
  - ✈️ Самолёты (данные OpenSky Network)
  - 🚢 Корабли (AIS-трансляция)
  - 🛰️ Искусственные спутники (CelesTrak)
  - 🌍 Землетрясения (USGS)
  - Погодные фронты, дорожные пробки и даже камеры видеонаблюдения (интеграция с публичными источниками)
- Переключение визуальных режимов:
  обычный, CRT-стиль (кинескоп), ночное зрение, тепловизионный (FLIR) – для разведки в любых условиях.
- Иммерсивные камеры:
  вид от первого лица из кабины пилота, тактический HUD с данными о целях, а также автоматический «режиссёр» для кинематографичных облётов планеты.
- Голосовое управление на русском языке – скажите, например, «Показать Москву», «Найти ближайший самолёт» или «Переключить ночной режим», и ИИ выполнит команду.
- Адаптивная производительность – оптимизация под слабые устройства и медленный интернет.

## 🗺️ Источники данных

Проект агрегирует информацию из множества открытых источников:

- OpenSky, ADS-B Exchange – авиация
- AISStream, MarineTraffic – судоходство
- CelesTrak, Space-Track – орбиты спутников
- USGS, EMSC – сейсмическая активность
- OpenWeatherMap – метеоданные
- Google Maps / HERE – дорожная обстановка

Все данные визуализируются в единой трёхмерной сцене с задержкой не более нескольких секунд.

## ⚙️ Установка и запуск

Проект написан на JavaScript (Node.js) и использует современные веб-технологии (Three.js, WebSocket, Express).

### Требования

- Node.js версии 16 или выше
- Современный браузер с поддержкой WebGL

### Шаги

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/paulafanasyev/-_-
   cd -_-
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Настройте переменные окружения – создайте файл `.env` в корне проекта и добавьте свои API-ключи для доступа к сервисам (список требуемых ключей приведён в `.env.example`).

4. Запустите сервер разработки:

   ```bash
   npm run dev -- --host localhost --port 4173
   ```

5. Откройте в браузере: http://localhost:4173

Для продакшн-сборки используйте `npm run build` и `npm run preview`.
